# 地点证据与命名

## 证据等级

- `verified`：素材 GPS 与地点位置吻合，并有画面特征/招牌及可靠网页交叉确认。
- `regional`：仅确认城市、老城、河流、产区、山谷或其他区域；标题使用这个范围，不细化到未确认的建筑。
- `visual`：无 GPS，但独特地标外观和可靠资料一致；明确标注为视觉判断。
- `unresolved`：没有足够证据；不写入标题，向用户提出具体确认项。

等级表示依据类型，不保证模型绝不出错。拍摄坐标可能缺失、失准或被代理文件复制；反向地理编码可能返回附近商家而非景点。

## 顺序

1. 读取经纬度，核对正负号、国家与拍摄行程；缺失时再查看原文件位置标签。不要把空值当成零坐标。
2. 根据地图找到候选地点。遵守地理编码服务的条款、缓存和速率限制；无必要不批量调用公共端点。
3. 看图：坐标是摄影机位置，镜头可能拍对岸建筑、远处桥梁。招牌可定位商家，但仍需要官方地址印证。
4. 查官方景点/旅游局/博物馆/地方政府资料。记录实际访问的页面 URL 和它支持的事实；搜索摘要不足时打开原页。不要声称查过未访问的资料。
5. 坐标、画面冲突时暂停具体地标命名。扩大到已确认区域，或询问用户；不要强行多数投票。

## 标题与说明

保持原名的变音符号，如 `DOBOGÓ` 中的 Ó。英文大写不是去掉重音符号。中文有常见译名时用常见译名；没有时使用一致的音译，并在说明中注明。英文可使用通行英文或本地专名，不把匈牙利语/斯洛伐克语强行伪装成英译。

同地不同镜头可重复地名；只有有证据时才细分为花园、白塔或某条街道。地点说明回答“在哪个国家/城市、是什么地方”，不杜撰建筑年代、历史故事或精确地址。
