# 旅行视频中英文地名标注 · Travel Place Titles

让AI根据 **素材GPS → 地图候选 → 画面/招牌 → 官方资料**，为达芬奇旅行视频逐镜头添加可编辑中英文地名。

这是一套 **AI Skill + Python辅助脚本**，不是独立地图模型，也不是安装后自动联网识别的达芬奇插件。研究和画面判断由支持视觉、联网和达芬奇连接的AI执行；脚本负责清单、计划校验、帧提取和标题写入。

## 能做什么

- 读取当前时间线与素材GPS，区分实拍、参考片、片头和边框。
- 区分摄影机所在地与画面拍摄的远处地标。
- 按证据输出具体景点、已确认区域或待确认镜头。
- 添加中文在上、英文大写在下的Fusion Text+标题，独立轨道，可编辑。
- 生成逐镜头地点说明、判断依据和资料来源表。
- 替换素材后检测旧计划失效，重新核对，避免套用旧标题。

## 安装到 Codex

先安装Git，然后执行下面的命令。目标文件夹已有内容时不要覆盖，先检查已有版本。

```bash
git clone https://github.com/versense84-cmd/travel-place-titles.git ~/.codex/skills/travel-place-titles
```

也可以下载仓库ZIP，将解压后含 `SKILL.md` 的目录命名为 `travel-place-titles`，放进 Codex 的 skills 目录。重新打开会话，让客户端发现新 Skill。其他支持SKILL.md的AI工具请按其Skill安装规则放置文件。

## 怎么调用

复制这句话到聊天里：

```text
$travel-place-titles
请给达芬奇当前时间线的每个旅行镜头添加中英文地名。
优先读取GPS，结合实际画面和网上资料核对地点。
中文在上，英文全部大写；不能确定的不要猜。
修改前备份时间线，标题放独立轨道，保留可编辑文字。
完成后给我地点说明和来源表。
```

也可以说：**“帮我给当前旅行视频的每个镜头标注中英文地名。”** 自动触发取决于AI客户端；`$travel-place-titles` 是显式调用Skill，不是终端命令。

替换镜头后：

```text
$travel-place-titles
我替换了当前镜头，请重新读取这段素材的位置并核对画面，
只更新对应的中英文地名，不沿用旧镜头的地点。
```

只做研究：

```text
$travel-place-titles
先分析当前时间线，输出中英文地点、判断依据和来源；暂时不要写入标题。
```

## 使用条件

1. 打开达芬奇项目和目标时间线。
2. AI可以通过Resolve连接器操作，或本地Python可以导入官方 `DaVinciResolveScript` 并连接达芬奇。具体配置以安装版本附带的 Developer/Scripting 文档为准。
3. AI具备图像查看和联网检索能力。Skill本身不提供搜索账号或模型API。
4. 本地Python 3；生成透明载体需要FFmpeg（`ffmpeg` 在PATH中）。核心脚本只用Python标准库，不含地理编码API密钥。
5. 使用可访问的原素材。代理文件、导出片可能没有GPS；无GPS时准确性取决于可辨识画面和行程信息。

跨客户端不保证同样的工具权限或执行效果。复杂转场、多机位、透明叠层需要人工/AI查看合成画面。当前 `capture` 小工具只支持整数NDF帧率，其余使用连接器适配，不能盲目换算。

## 脚本命令与数据

参见 [Resolve工作流](references/resolve-workflow.md)，提供完整命令行示例。

`inspect` 只读取；`apply` 默认也只校验，明确加 `--apply` 才写入。写入前自动复制备份时间线，发现实拍ID/媒体/时间范围发生变化时拒绝沿用旧计划。计划里的 `unresolved` 行不会生成标题。

示意字段（由inspect生成项目身份和真实范围后填写，不要照抄成实际计划）：

```json
{
  "cn": "示例城堡",
  "en": "EXAMPLE CASTLE",
  "confidence": "verified",
  "evidence": "GPS与官方地址吻合，代表帧的门楼外观一致",
  "sources": ["https://example.org/official-place-page"]
}
```

**保存透明MOV载体**：Fusion标题仍依赖本地载体文件。不要把它当临时缓存删除。

## 隐私与准确性

公开仓库不包含真实旅行素材、用户路径、GPS记录和截图。运行时生成的清单、帧和计划留在自己的 `work/` 目录，不应提交GitHub。联网核对只发送必要的地点信息；不要默认把视频上传第三方。

GPS不是景点答案，附近镜头不是同地点保证。中文音译会注明，地图/招牌/画面冲突时使用可确认的区域或请求具体确认。所有地点名称应保留来源，不能承诺“所有镜头100%自动准确”。
